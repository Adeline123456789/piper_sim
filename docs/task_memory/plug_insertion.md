## effort 字段纠正

本项目没有六维力/力矩传感器，没有实测接触力或力矩。历史文件的 `effort_Nm`、`effort_rmse_sdk_nm` 是按SDK描述缩放的反馈字段；未独立核实其来源、物理单位与驱动力换算。它不能当成实测关节力矩、夹爪法向力或接触力矩。没有外置传感器并不排除驱动器内部估算，但本项目没有验证这种估算。

撤回“实测力矩轨迹匹配”的表述。官方sysid试验只拟合了开度与未标定的effort代理信号，不构成有效的受力辨识。保留原始文件不篡改历史记录，本说明覆盖历史报告对该字段的物理解释。

原始指令、关节/夹爪位置记录、视频仍可作为各自的观测数据；它们不自动给出绝对接触力。所有未经独立验证的摩擦、COM、惯量和驱动换算值仍是估计/候选。
